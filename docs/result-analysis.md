# 勤務結果の分析

## 編集先

- `scripts/core/result_analysis.gd`: 保存済みスナップショットの集計。しきい値は`RULES`、組み合わせ文は`COMBINATIONS`、図の横の短い分析は`radar_findings`。現行教材や実時間を参照しない。
- `scripts/ui/result_analysis_view.gd`: 結果→主要指標→三角形と短い分析→分野別横棒→アドバイス。「判断力・確認力」内は左が図、右が3指標の実績。分野別は全幅。
- `scripts/ui/result_radar.gd`: 3軸の描画とラベル。全軸にデータがある場合だけ面を塗り、未評価の軸は点線・未評価表示。0％とは区別する。
- `scripts/ui/desk.gd` / `desk_layout.gd`: 分析・振り返りの2タブ。助言は問題インデックスで絞込。振り返りタブを再選択すると全件に戻る。PageUp/PageDown/Home/EndとTabのフォーカス追従を維持。
- `tests/test_result_analysis.gd`: しきい値・少数・旧記録・非表示設定・復習導線・スクロールの検証。

## 指標の注意点

- 正答率は回答数が分母。分野ごとに件数も表示し、未出題は0点にしない。件数に関係なく、ツールチップは正答率とクリック操作の案内のみ。
- 調査操作数はobservationsからskippedを除いた件数。失敗を含む。資料の再表示や入力不足でUIが止めた操作は記録されない。送信見送り自体には得点を付けない。
- 必要情報充足率はmissing_evidenceが空の問題の割合。初期情報だけで足りる問題を含み、読解力や丁寧さの点数ではない。
- 時間は既存elapsed_seconds。速度・操作数はタイプ判定に使わない。
- 時間の棒は実時間に合わせて上限を切り上げた目盛り（0と上限を明記）。目標や得点ではなく、異なる勤務の棒の長さは比較できない。時間と調査回数は合計のみ表示し、平均表示は設けない。問題ごとの時間は推定しない。
- 調査の帯は実行完了・実行失敗の内訳。完了は安全・適切の意味ではない。以前の「未評価」はcorrect_usage未設定の操作で、プレイヤー向け表示から除外。適否未設定も完了に含め、送信見送りは総数に含めない。不適切調査の集計・診断・助言は維持。
- 不適切な調査はokかつcorrect_usage=falseの記録。外部照会以外にも設定可能なので、外部送信だけとは表記しない。

三角形は0～100％の3軸。危険を見抜く=正しくBLOCK/正解BLOCKの出題、安全を見分ける=正しくALLOW/正解ALLOWの出題、根拠をそろえる=必要情報充足/回答。正答率・調査の適切さは図から削除。分母0は未評価とし、0点や100点に補完しない。割合と件数・短い実績文は図の右、定義はツールチップに表示。未出題を成功扱いせず、誤答の原因は推測しない。情報確認は初期情報だけで足りる問題も含み、スタイルの確認率とは分母が異なる。描画高260px・半径108px、上部ラベルと頂点の余白を確保。外周の説明・分野別の下部案内は表示しない。

結果と主要指標を上部に置き、全幅の図・分野別・アドバイスへ縦スクロールする。「詳しい数値」「良かった点」「次に伸ばせる点」は表示しない。判定根拠はタイプ名のツールチップで確認できる。正解非表示の教材では三角形を表示しない。

## 今回の判定と設計上の判断

旧「確認状況×許可/遮断の偏り」の6タイプを、スタイルと到達レベルに置換。保存済みの回答記録から計算する。

表示は内部判定と分離する。5問未満、追加調査対象が3問未満、調査要否の記録不足などでレベルが参考判定またはスタイルが保留の場合、`profile()`は「セキュリティチャレンジャー」と学習を促す短文だけを表示。「参考」「スタイル判定保留」や級は付けない。5問以上でスタイルの記録条件を満たせばスタイル×級を表示。グラフの対象数0は引き続き未評価とする。

`retry_of`のある再挑戦結果は、件数や内部判定に関係なく「復習者」と表示する。通常の勤務結果には上記の判定を使う。

- スタイルは追加調査対象の必要情報充足率だけ。80%以上は慎重型、50%以下は直感型、その間は中間。対象3問未満、または調査要否の記録が一部でも欠ける場合は保留。
- 正答率70%未満は初心者級、以上は実践級。通常判定の下限は`level_min_cases=5`、プロ級の下限は`pro_min_cases=10`で別管理。プロ級は10問以上・90%以上に加え、中級以上で3問以上**正解**、ALLOW/BLOCK各1問以上出題、慎重型の確認条件、危険な許可と不適切調査0件、全問の既知難易度が必要。
- プロ級は根拠確認を優先し、直感型・中間との組み合わせを作らない。今回の範囲の教材内評価で、資格や心理尺度ではない。判定は丸める前の比率で行う。
- 初級・中級・上級を認識。未評価や旧分類の不明な値を高難度と推測しない。範囲は回答記録から作り、未評価を含む勤務ではプロ級を保留する。
- 助言は不適切調査→危険な許可→誤答の多い分野→正解でも情報不足の順。該当問題だけを復習できる。見た箇所や誤答の原因は断定しない。
- `show_expected`と`show_reason`が両方trueのときだけ、プロフィール・判定根拠・具体的助言と復習リンクを表示する。
- 学習テーマ・問題別時間の記録は未追加。教材へのタグ付与と保存、時間の計測境界を設計してから拡張する。合計時間を各問の実時間として扱わない。

## 保存互換

新規履歴はversion 3、旧version 2も読み込む。形式・読込元の扱いは [学習支援](learning-support.md)。`investigation_required` はrequired_evidenceが初期情報だけでは満たせない場合true（代替証拠も考慮）。

既存のversion=2履歴も読める。項目のない履歴は基本分析を表示し、スタイル・プロ級は保留（現在の教材から補完しない）。分析結果は保存せず閲覧時に計算するため、ルール変更は過去履歴にも反映される。当時の判定固定が必要になったら別途バージョン付き保存を設計する。新項目を知らない旧アプリでの読込互換は保証しない。

履歴一覧の索引・100件上限・保存失敗時の再試行は既存処理を使用する。
